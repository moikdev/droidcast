# Compact menus and caller selection

This slice of [#91](https://github.com/moikdev/droidcast/issues/91) makes searchable Actions usable in a short keyboard viewport, adds a touch keyboard toggle on every width, and preserves the launcher's selected text while a menu borrows focus. Category containment uses live same-callback geometry. The original category failure was an observer error; it earns no production containment-fix claim.
