# Emoji copy history

The picker previously saved each copied symbol and used the list to rank results without asking. Fresh installations and upgrades now start with history off. A copy still puts the complete symbol on the clipboard. In Recent, **Enable recent history** opts in to remembering up to 32 distinct symbols and makes any existing entries visible again. Pausing removes their influence on search and hides the list. **Clear saved emoji history** removes it while preserving the current recording choice and favorites. Both actions are available from Recent → Actions, including Ctrl+K on an empty list. The list contains local catalog IDs. Favorites and recents stay outside portable backups. Clearing while enabled let the next copy start a new list.

A tablet run used Android input taps to change the setting and force-stopped the app twice. Each stop verified that the main process had exited before relaunch. The [first relaunch](screenshots/emoji-history/restart-enabled.png) showed the saved flag. The [Actions menu](screenshots/emoji-history/history-actions.png) offered Pause and Clear. [Clearing while paused](screenshots/emoji-history/cleared.png) removed the stored list while retaining the seeded favorite. The hierarchies and screenshots were taken sequentially.
